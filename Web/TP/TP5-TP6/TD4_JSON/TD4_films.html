La fonction includes() indique si une sous-chaîne est présente (true ou false) dans une chaîne, par exemple :
let uneChaine = "Bonjour";

Méthodes de recherches et de traitement des tableaux en javaScript

JavaScript propose plusieurs méthodes permettant de parcourir un tableau afin de rechercher des éléments ou d'effectuer des traitements. Nous allons étudier quatre méthodes : filter(), find(), some() et reduce().

1. La méthode filter() - permet de récupérer tous les éléments d'un tableau qui respectent une condition.
->Elle retourne un nouveau tableau contenant les éléments sélectionnés.
Syntaxe : let resultat = tableau.filter(element => condition);

Exemple 4 : Rechercher tous les films diffusés à l'UGC Les Halles.

const resultats = films.filter(film =>
    film.cinema === "UGC Les Halles"
);
afficherResultats(resultats, 'resultatExemple4');

//Ce code équivaut à :
let resultats = [];
films.forEach((unFilm) => {
    if(unFilm.cinema === 'UGC Les Halles'){
        resultats.push(unFilm);
    }
});

Méthodes de recherches et de traitement des tableaux en javaScript

2. La méthode find() : permet de rechercher le premier élément d'un tableau qui respecte une condition.
->Elle retourne directement l'élément trouvé et non un tableau. Si aucun film ne correspond à la condition, la méthode retourne undefined.
Syntaxe : let resultat = tableau.find(element => condition);
Exemple :
Rechercher un film dont le titre est « Le rêve et le cristal ».
let resultat = films.find(film =>
    film.titre === "Le rêve et le cristal"
);
La variable resultat contient l'objet correspondant au film.

Exemple 5 : Rechercher le film dont le tritre est "Le rêve et le cristal"

const unFilm = films.find(film =>

if (unFilm !== undefined){

Méthodes de recherches et de traitement des tableaux en javaScript

3. La méthode some() : permet de vérifier une condition avec une réponse booleéenne
Syntaxe : let resultat = tableau.find(element => condition);
Exemple :
Vérifier si l'actrice Anaïs Demoustier joue dans au moins un film.
let resultat = films.some(film =>
    film.acteurs.includes("Anaïs Demoustier")
);
La variable resultat contient true ou false en fonction du résultat.

Exemple 6 : l'actrice "Anaïs Demoustier" joue t-elle dans au moins un film ?

const reponsePositive = films.some(film =>
    film.acteurs.includes("Anaïs Demoustier")
);
let resultat;
if(reponsePositive){
    resultat = "Oui, Anaïs Demoustier joue dans 1 ou plusieurs films";
}
else{
    resultat = "Non, Anaïs Demoustier ne joue dans aucun film";
}
document.getElementById('resultatExemple6').textContent = resultat;


//Ce code équivaut à :
let reponsePositive = false;
let i = 0;
while(i < films.length && !reponsePositive){
    if(films[i].acteurs.includes("Anaïs Demoustier"){
        reponsePositive = true;
    }
    else{
        i++;
    }
}

Méthodes de recherches et de traitement des tableaux en javaScript

4. La méthode reduce() : permet de cumuler une valeur avec une donnée du flux JSON
Syntaxe : let resultat = tableau.reduce((accumulateur, element) => {
                                   return accumulateur + element.valeur;
                             },valeur d'initialisation );

Exemple :
Quel est le chiffre d'affaires cumulé de tous les films ?
let caCumule = films.reduce((ca,film) =>{
        return ca + film.recettes;
      },0);
La variable caCumule contient le cumul des recettes de tous les films.

Exemple 7 : Quel est le chiffre d'affaires cumulé de tous les films ?

let caCumule = films.reduce((ca,film) =>{
        return ca + film.recettes;
      },0);

const resultat = "Chiffre d'affaires cumulé de tous les films : " + caCumule.toFixed(2) + " M€";
document.getElementById('resultatExemple7').textContent = resultat;


//Ce code équivaut à :
let caCumule = 0;
films.forEach((unFilm) => {
    caCumule = caCumule + unFilm.recettes;
});

Dictionnaire associatif en javaScript : map

Un objet map permet de manipuler une collection de clé/valeur
Syntaxe : let genres = new Map(); // par exemple on veut connaître le nombre de films par genre -> map de type string/number


Les primitives :
Méthodes et propriétésRôleExemple
set(clé, valeur)Ajouter ou modifier une entréegenres.set("Drame", 25)
get(clé)Récupérer une valeurgenres.get("Drame")
has(clé)Vérifier si une clé existegenres.has("Drame")
delete(clé)Supprimer une entréegenres.delete("Drame")
clear()Vider la Mapgenres.clear()
sizeNombre d'entréesConsole.log(genres.size)

keys()Obtenir un itérateur sur les clés
values()Obtenir un itérateur sur les valeurs
entries()Obtenir un itérateur sur les couples clé/valeur
Exemple forEach : Parcourir les clés et les valeurs

genres.forEach((valeur, cle) => {
   console.log(cle + " : " + valeur);
});

Exemple keys : Parcourir les clés

for (const genre of genres.keys()) {
   console.log(genre);
}

Exemple values : Parcourir les valeurs

for (const nombre of genres.values()) {
   console.log(nombre);
}

Exemple values : Parcourir les couples clé/valeur

for (const [genre, nombre] of genres.entries()) {
   console.log(genre + " : " + nombre);
}
